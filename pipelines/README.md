# Pipelines

Each folder is one pipeline, self-contained: `pipeline.py` (registered under the folder name),
`config.yaml` (default hyper-parameters), `prompts/`, `README.md` (the 11 mandatory sections)
and `diagram.mmd` with its rendered `diagram.svg`. Folders starting with `_` are templates and
are never run. To add a pipeline, copy [`_template/`](_template/) and follow
[AGENTS.md](../AGENTS.md#add-a-pipeline); nothing outside the new folder and its experiment
yaml needs to change.

Detection pipelines are named `pNN_*`, classification pipelines `cNN_*` (decision D2).
