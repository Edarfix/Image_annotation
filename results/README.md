# Results

| Path | Content | In git |
|---|---|---|
| `runs/<date>_<pipeline>_<dataset>_<setting>_<hash>/` | One run: resolved config, predictions, metrics, timings, failures, errors, visualisations, log | Only `metrics.json` and `config.resolved.yaml` |
| `concept_cards/<dataset>/` | Concept cards compiled by pipelines (p02+), editable by hand | Yes |
| `leaderboard.md` | Pipeline × dataset table, generated by `scripts/make_leaderboard.py` | Yes |
| `reports/` | Final reports, e.g. `rf100vl_<date>.md` | Yes |

Anything about a proprietary dataset goes to a sibling folder ending in `_private` (e.g.
`runs_private/`, `concept_cards_private/`), which git ignores.
