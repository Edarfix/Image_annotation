# M1–M3 progress recap: first pipelines running (2026-10-28)

A first pass through M1, M2 and M3, so that pipelines run end to end on the cluster. None of
the three milestones is closed: what is missing is listed under TODO.

## What works

- **Review fixes of M0** (each with a regression test; details in `improvement.txt`):
  - private 0600 files from atomic writes;
  - numpy values breaking JSON;
  - `few_shot` passing the domain (D4);
  - `1e-3` read as a string;
  - `data` symlink not ignored by git;
  - mermaid setup not installing its browser.
- **RF100-VL (M1).**
  - All 100 datasets converted from the HF mirror to COCO folders (`$OVANNOT_DATA/rf100vl`,
    no image size mismatch).
  - `rf100vl` loader, with few-shot exemplars from the train split and domains from the
    official package.
  - Dev subset fixed by a rule (D12, confirmed by the owner).
- **Evaluation (M1).** COCO mAP / AP50 / AP75 at maxDets 500 (D15), precision, recall and F1 at
  IoU 0.5 at the operating threshold, and per-class metrics. Sanity tests are green: ground
  truth scores 1, empty predictions score 0, shifted boxes lower the mAP monotonically.
- **Models (M2).**
  - Disk cache of every call.
  - OpenAI-compatible MLLM client, with the Qwen3-VL box format checked in the official
    cookbook.
  - SAM 3 HTTP client and server (transformers 5.13 API checked in the container).
  - vLLM and SAM 3 launch scripts with health checks (D13).
- **Runner (M3).**
  - Resumable runs, thread pool, per-dataset predictions, metrics, timings and failures.
  - Run summary with means per domain; `scripts/run.py`, `scripts/make_leaderboard.py`, and a
    SLURM script that serves the models, then smoke-tests and runs.
- **Pipelines.**
  - `p01_mllm_grounding_raw`: smoke test passed on the cluster, run on the dev subset.
  - `p00_sam3_raw`: implemented and tested with a fake SAM 3 only; the server code has not
    run yet, because the weights are gated.
- **Tests.** 79 pass locally (CPU) in a few seconds, and the GPU smoke test passes for p01.
  ruff is clean.

## Decisions and why

- D12: RF100-VL from the HF mirror; dev subset by rule (largest `valid` split per domain).
- D13: models served over HTTP from the shared vLLM Apptainer image; the ovannot environment
  stays CPU-only.
- D14: Qwen3-VL-30B-A3B for p01 until the 235B is downloaded; MLLM boxes score 1.0.
- D15: AP read from the precision array at maxDets 500. `COCOeval.summarize` gives -1 for
  maxDets (1, 10, 500), the same bug detectron2 patches.
