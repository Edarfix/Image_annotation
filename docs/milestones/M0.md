# M0 recap: skeleton, contract, papers (2026-10-23)

## What works

- **Tooling.**
  - `uv` project, Python ≥ 3.11, with a lock that covers both Linux architectures.
  - ruff and pytest: 50 tests pass locally, without GPU or network.
  - Heavy GPU dependencies are deliberately absent until M2 (D11).
- **Core contract** (`src/ovannot/core`).
  - Shared types for both tasks, with a JSON round trip.
  - Exceptions mapped to failure kinds.
  - Plugin registries that import `pipelines/` and `datasets/` folders by path (D8).
  - YAML configs with `extends`, dotted overrides and a stable hash.
  - The dataset-loader contract, which keeps ground truth away from pipelines and strips what
    a setting does not allow (D4).
  - The `Pipeline` base class with `stage()`, which times stages and records failures.
  - COCO I/O and a lazy `ModelHub`.
- **Utilities.** Box geometry (IoU, NMS, context crops), hashing, atomic writes, prompt
  rendering that fails on missing variables.
- **Papers.**
  - The 14 papers of the brief plus 2 for task 1, with arXiv versions pinned.
  - Every id matched its title, both against the arXiv API and the PDF's first page.
  - PDFs downloaded (217 MB, git-ignored). One reading note per paper in
    [papers/README.md](../../papers/README.md), written from the PDFs.
- **Pipeline template.**
  - A runnable `_template` with config, prompt file, 11-section README and a diagram rendered
    with mermaid-cli (installed under `.tools/`, pinned, about 950 MB).
  - Contract tests check every pipeline folder.
- **Documentation.** The brief in English, the decision log (D1–D11), README, AGENTS.md and
  the section READMEs.

## Decisions and why

- **Agreed with the owner.**
  - D1: package `ovannot`, because classification is in scope.
  - D2: task 1 with a "none" answer.
  - D3: global tuning on the `valid` split of 5 dev datasets; test reported on all 100 and
    the 95 held-out datasets.
  - D5: no model above ~1T parameters (Kimi K3 dropped).
  - D6: mermaid-cli installed locally, SVGs committed.
  - D7: commits on `main`.
- **Taken as defaults (open to change).**
  - D4: zero-shot means class names only. This is the paper's protocol, and the runner
    enforces it.
  - D8: plugins imported by path. A top-level `datasets` package would clash with Hugging
    Face `datasets`.
  - D10: download only the RF100-VL FSOD variant, since we never fine-tune.
  - D11: GPU dependencies as cluster-only extras.
- **D9, task 1 benchmark: proposed, needs the owner's confirmation.** No public multi-domain
  classification benchmark with a "none" answer exists, so we combine:
  - ELEVATER's datasets, from a mirror because the official host is dead;
  - a fixed per-dataset class split;
  - Miller et al.'s open-set metrics.

  Reading the PDF corrected the first version of D9. Miller et al. remove each image's own
  class from its query set, which would leak the answer to pipelines that prepare on the full
  class list.
